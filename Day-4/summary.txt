CSS CONCEPTS EXPLAINED WITH CODE EXAMPLE
=============================================

Reference Code:
---------------
#about {
    color: red;
    width: 300px;
    border: 15px solid green;
    border-radius: 50px;
    padding: 20px;
    margin: 50px;
}


1. CSS INTRODUCTION
-------------------
CSS (Cascading Style Sheets) is used to style and layout HTML elements. 
It controls colors, fonts, spacing, borders, and positioning. 
The code above demonstrates styling an element with the ID "about" by applying various visual properties.


2. CSS SYNTAX
-------------
Syntax: selector { property: value; }

Structure:
- Selector: Targets which element(s) to style
- Property: What aspect to change (color, width, border, etc.)
- Value: The setting for that property
- Semicolon: Required to end each declaration



3. SELECTORS
------------
Types of selectors:

a) Element Selector: p { } - Targets all <p> elements
b) Class Selector: .classname { } - Targets elements with class="classname"
c) ID Selector: #idname { } - Targets element with id="idname"
d) Universal Selector: * { } - Targets all elements




4. INTERNAL AND INLINE CSS
---------------------------
a) External CSS: Stylesheet link in HTML <link rel="stylesheet" href="style.css">
b) Internal CSS: <style> tag in HTML head
c) Inline CSS: style attribute on HTML element
   Example: <div style="color: red;">Text</div>




5. COMMENTS IN CSS
------------------
Syntax: /* Comment here */

Example: /* This styles the about section */
Used for explaining code to yourself and other developers


6. COMMON CSS ERRORS
---------------------
- Missing semicolon: color: red (should be color: red;)
- Wrong selector: .about instead of #about for ID
- Typo in property: colr instead of color
- Missing unit: width: 300 (should be width: 300px)
- Incorrect value: border: green (missing width and style)


7. COLORS
---------
Ways to specify colors:

a) Named Colors: red, green, blue, white, black, etc.
b) Hex Values: #FF0000 (red), #00FF00 (green)
c) RGB Values: rgb(255, 0, 0) (red)
d) HSL Values: hsl(0, 100%, 50%) (red)



8. BACKGROUND (color, image, repeat)
-------------------------------------
a) Background Color: background-color: skyblue;
b) Background Image: background-image: url('image.jpg');
c) Background Repeat: background-repeat: repeat | no-repeat | repeat-x | repeat-y;
d) Background Position: background-position: center;
e) Shorthand: background: url('img.jpg') center no-repeat;
\

9. BORDER
---------
Border Properties:

a) Border Width: border-width: 15px;
b) Border Style: border-style: solid | dashed | dotted;
c) Border Color: border-color: green;
d) Shorthand: border: 15px solid green;
e) Border Radius: border-radius: 50px; (rounds corners)




10. MARGIN
----------
Margin: Space OUTSIDE the border (external spacing)


11. PADDING
-----------
Padding: Space INSIDE the border (internal spacing around content)






12. HEIGHT AND WIDTH
--------------------
Height: vertical size of element
Width: horizontal size of element

Syntax:
- width: 300px; (absolute pixels)
- width: 50%; (percentage of parent)
- min-width: 100px; (minimum width)
- max-width: 500px; (maximum width)

13. BOX MODEL
-------------

Layer Breakdown:
1. Content: The actual content (width: 300px in our code)
2. Padding: 20px space around the content
3. Border: 15px green border around padding
4. Margin: 50px space outside the border
